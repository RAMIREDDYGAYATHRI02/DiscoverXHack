# AI usage

AI assistance was used to interpret the supplied ShiftSwap problem statement, design the API and MongoDB state transitions, implement the React/Vite dashboard and Django REST Framework backend, and write the automated tests and project documentation.

The implementation was reviewed against the requirements for exact seed preservation, idempotent initialization, claim-rule boundaries, claim availability ordering, manager approval revalidation, access rules, and concurrent state changes. The code and decisions were kept in this repository for human review. No paid service or model API key is required to run the project.
